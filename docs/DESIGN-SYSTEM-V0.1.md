# CA OS — Design System V0.1

Direction : **Pilotage Premium — Proposition B**.

Principes : bleu nuit, surfaces blanches, zone de travail claire, hiérarchie forte, densité maîtrisée, couleurs fonctionnelles non exclusives, focus visible, tailles tactiles mobiles.

Composants produits : CA-Button, CA-Card, CA-KPI, CA-Status, CA-Alert, CA-Table, CA-Action, CA-Decision, CA-ProjectHeader, CA-Search, CA-EmptyState, CA-ErrorState, CA-Loader, CA-Modal, CA-Drawer, CA-Toast.

Chaque statut associe un libellé textuel à la couleur. Les tableaux deviennent des cartes/listes sur mobile.
