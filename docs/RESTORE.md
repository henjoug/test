# Reprise / restauration minimale — V0.1

1. Ne pas supprimer la source de données d’origine.
2. Conserver l’ID d’instance et une sauvegarde/export du Google Sheet.
3. Réinstaller la même CA_OS_VERSION si nécessaire.
4. Restaurer la configuration d’instance (providers + IDs).
5. Vérifier SCHEMA_VERSION avant toute migration.
6. Exécuter le diagnostic.
7. En cas d’échec de migration, revenir au fichier de données sauvegardé et à la version produit précédente documentée.
